# 승인 공식문서 임베딩 비교 v1

측정일은 2026-08-28이며 외부 다운로드 없이 저장소 밖 로컬 반입 모델만 사용했다.
평가 corpus는 `APPROVED/ACTIVE`인 공식문서 5개의 113개 청크다. 공식 검수 후보 중
이 corpus로 완전히 근거를 확인할 수 있는 답변형 21개와 공통 무응답형 6개를 동일하게
사용했다. 이 27개 질의는 모델 비교용 잠정 데이터이며 사람의 질의-근거 최종 검수를
완료한 운영 골든셋은 아니다.

## pgvector 적재 검증

격리 PostgreSQL 17과 pgvector 0.8.1에 동일한 113개 `chunk_id`를 모델별로 적재했다.

| 모델 | 차원 | 저장 벡터 | 검증 결과 |
|---|---:|---:|---|
| `intfloat/multilingual-e5-small` | 384 | 113 | 모든 `vector_dims=384` |
| `dragonkue/snowflake-arctic-embed-l-v2.0-ko` | 1024 | 113 | 모든 `vector_dims=1024` |

모델별 HNSW partial index와 `(chunk_id, model_id, model_version)` 복합 기본키가 적용되어
두 모델의 벡터가 공존하며 서로 덮어쓰지 않음을 확인했다.

## 동일 기본 설정 비교

기본 설정은 keyword `0.35`, vector `0.65`, vector threshold `0.15`, result threshold
`0.35`다.

| 지표 | E5-small | Arctic-ko |
|---|---:|---:|
| Recall@3 | 0.2381 | 0.9048 |
| Recall@5 | 0.2857 | 0.9048 |
| MRR | 0.2103 | 0.8254 |
| nDCG@10 | 0.2404 | 0.8420 |
| 무응답 오탐률 | 1.0000 | 0.5000 |
| 정책 위반 | 0 | 0 |

현재 공식 한국어 문서에서는 Arctic-ko가 E5-small보다 명확히 우세하다. 다만 두 모델 모두
기본 품질 게이트를 통과하지 못했다.

## 동일 튜닝 그리드 비교

125개 조합을 동일하게 평가했다. Arctic-ko 최선 조합은 keyword `0.2`, vector `0.8`,
vector threshold `0.15`, result threshold `0.4`였다.

| 지표 | E5-small 최선 | Arctic-ko 최선 |
|---|---:|---:|
| Recall@3 | 0.2381 | 0.9048 |
| Recall@5 | 0.2857 | 0.9048 |
| MRR | 0.2103 | 0.8571 |
| nDCG@10 | 0.2404 | 0.8696 |
| 무응답 오탐률 | 1.0000 | 0.1667 |
| 정책 위반 | 0 | 0 |

Arctic-ko의 남은 답변형 미적중은 `ORC-020`, `ORC-024`이고, 남은 무응답 오탐은
`ORC-028`이다. 무응답 목표 `0.10`을 넘으므로 운영 기본 모델로 자동 승격하지 않는다.
다음 단계는 세 질의의 근거·무응답 경계를 사람이 재확인하고, 검색 후 정책성 요청을
차단하는 abstention gate를 별도로 평가하는 것이다.

## 평가 성능 개선

기존 평가기는 각 질의와 튜닝 조합마다 passage 임베딩을 반복 계산했다. 평가 실행 범위에서
query와 passage 임베딩을 모델 입력 문자열별로 캐시하도록 변경했다. 점수와 순위 산식은
유지하면서 Arctic-ko 기본 평가 시간을 수분대에서 약 30초로 줄였다.
