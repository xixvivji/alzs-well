# 질의 의도·직접 답변성 검색 검증 v1

## 결론

검색 의도와 무관한 선행 표현을 임베딩·키워드 검색 전에 제거하고, 문서 유형 권위보다
질문에 직접 답하는 관련성 점수를 우선하도록 평가기와 PostgreSQL 검색을 일치시켰다.
정의 질의는 `제N조(정의)` 제목에 설명 가능한 고정 보정값 `0.08`을 적용한다.

사용자가 수정 후 업무 의미의 적절성을 승인한 아래 6건은 모두 기대 근거가 Top-1이다.

| 질의 | Top-1 근거 | 결과 |
|---|---|---|
| `IRC-082`~`IRC-085` | 법률 `제2조(정의)`의 피해환급금 정의 | 4건 모두 `PASS_TOP_1` |
| `IRC-101`, `IRC-104` | 시행령 `제10조의6(전기통신금융사기 정보의 제공 등)` | 2건 모두 `PASS_TOP_1` |

## 변경 원칙

- `고객에게 안내하려고 합니다`, `행원 검토용`, `어려운 표현 없이 쉽게 설명`처럼
  답변 표현만 지시하는 첫 문장은 검색 의도를 바꾸지 않으므로 검색어에서 제외한다.
- 법률이라는 이유만으로 더 직접적인 시행령 근거보다 앞세우지 않는다. 결합 관련성 점수를
  먼저 비교하고 문서 권위는 점수가 같을 때만 사용한다.
- `뜻`, `의미`, `정의`, `무엇을 말하는지`가 포함된 정의 질의에만 정의 조항 보정을 적용한다.
- ACL, audience, 승인·효력기간, 미래 시행 조문 제외와 고위험 무응답 정책은 변경하지 않는다.
