# 공식문서 검색 골든셋 후보 v1

기준일은 2026-08-27이다. 저장소의 공식 manifest 7개를 원문 해시 검증부터 HTML/PDF 추출,
정규화, 구조 기반 청킹까지 메모리에서 처리하여 116개 검수 전용 청크를 만들었다. 이 중
질문 의도와 근거가 한두 청크 안에서 명확히 대응하는 사례만 1차 후보로 선정했다.

## 범위

| 구분 | 수량 |
|---|---:|
| 공식 반입 문서 | 7 |
| 검수 전용 청크 | 116 |
| 답변형 후보 | 24 |
| 무응답형 후보 | 6 |
| 사람 판정 완료 | 0 |

모든 공식 manifest는 `approvalStatus: IN_REVIEW`,
`lifecycleStatus: PENDING_ACTIVATION`, `usageRights: REVIEW_REQUIRED`를 유지한다. 검수 전용
청크는 운영 검색 저장소나 pgvector에 적재하지 않는다.

## AI 1차 검토 결과

- 비대면 계좌개설 안심차단 Q&A는 질문-답변 단위 7개 청크가 명확하여 우선 검수 대상으로
  적합하다.
- 대면편취형 보이스피싱 안내는 대상 확대와 절차·기한을 각각 한 청크에서 확인할 수 있다.
- 지정인 알림서비스는 내용은 사용할 수 있으나 HTML 구조 제목이 부족하고 같은 긴 제목이
  반복된다.
- 금융거래 안심차단 안내는 하나의 광범위한 청크라 세부 질의 확대 전에 재청킹 검토가
  필요하다.
- 착오송금 반환지원 원문은 첫 청크에 메뉴·탐색 문구가 섞여 있으므로 해당 청크를 정답
  후보에서 제외했다.
- 법률 67개, 시행령 33개 청크는 PDF 법령 구조 모드로 재생성했다. 조 제목과
  본문을 분리하고 항·호·목을 검색 본문에 보존하여, 페이지 경계에서 누락되던
  전기통신금융사기 정의의 4개 목과 사기정보 즉시 파기 3개 예외를 복원했다.
- 의료 진단, 투자추천, 개별 고객 적격성의 최종 승인, 고객 연락·계좌 정지 같은 금융 실행,
  근거 없는 미래 법령 및 개인정보 요청은 `ABSTAIN` 후보로 포함했다.

## 사람이 확인할 항목

1. 질문의 날짜·금액·대상·예외 조건이 `evidenceExcerpt`와 원문에 모두 존재하는지 확인한다.
2. 법령·시행령은 `sourceUrl`과 페이지 번호로 조문 경계를 다시 확인한다.
3. 적절하면 `ACCEPTED`, 틀리면 `REJECTED`, 질문 또는 근거 수정이 필요하면
   `AMBIGUOUS`로 판정한다.
4. 판정 이유와 수정안은 `reviewComment`에 남긴다.
5. 이 판정과 공식문서 `APPROVED/ACTIVE` 전환은 별개로 처리한다.

최소 한 명의 업무 담당자와 한 명의 준법·지식관리 검토자가 독립적으로 확인한 뒤 합의된
`ACCEPTED` 행만 공식 검색 평가 데이터셋으로 승격한다. 그 전에는 Arctic-ko 운영 기본 모델
선정이나 기능 플래그 활성화의 근거로 사용하지 않는다.
