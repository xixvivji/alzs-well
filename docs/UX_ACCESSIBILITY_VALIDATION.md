## 적용 사항

- 고객·행원·관리자 공통 본문 바로가기와 명확한 `main` landmark
- 현재 메뉴의 `aria-current="page"`와 역할별 내비게이션 이름
- 모든 주요 버튼·입력의 최소 44px 조작 영역과 명확한 포커스 표시
- 큰 글씨·고대비 설정의 `aria-pressed` 상태 및 브라우저 내 유지
- 비동기 로딩의 `aria-busy`·`aria-live`, 오류의 `role="alert"`
- 로그인·행원 메모 입력의 도움말 연결
- 전역 오류·404 화면의 다시 시도·처음 화면 복구 경로
- `prefers-reduced-motion`에 따른 애니메이션 최소화
