# AI 코파일럿 출력 정책

| 항목 | 값 |
|---|---|
| 문서번호 | AW-POL-005 |
| 버전 | 1.0-draft |
| 적용 | 템플릿 및 향후 내부 호스팅 모델 |
| 승인자·시행일 | TBD |

## 역할

코파일럿은 사실 요약, 중립 질문, 체크리스트, 승인된 근거 인용을 생성하는 읽기 전용 보조도구다. 상태·심각도·서비스 적격성·연락·금융실행을 결정하지 않는다.

## 입력 허용 목록

- 사건·경보 ID의 내부 참조값
- 사유코드와 불변 근거 요약
- 고객이 선택한 구조화 응답 코드
- 미확인 항목
- 정책엔진이 이미 허용한 서비스 후보
- 검색 단계에서 권한과 효력기간을 통과한 문단

성명, 계좌번호, 주민등록번호, 연락처, 자유형 상담 원문은 기본적으로 프롬프트에서 제외한다. 필요성이 승인된 필드는 마스킹·최소화한다.

## 출력 필수 구조

- `summary`: 판단이 아닌 확인된 사실과 미확인 사실
- `suggestedQuestions`: 비유도·비진단 질문
- `checklist`: 행원이 확인할 항목
- `basisReasonCodes`: 정책엔진 입력과 일치
- `citations`: 문서 ID·버전·문단·기준일
- `generatedBy`, `modelVersion`, `fallbackUsed`

## 거부·폴백

근거 없음, 권한 없음, 만료 문서, 인용 불일치, 프롬프트 인젝션, 모델 오류 또는 제한시간 초과 시 생성 결과를 버리고 `DeterministicCopilotAdapter`의 검증된 템플릿으로 폴백한다. 현재 P0의 정상 권위 경로는 `DETERMINISTIC_TEMPLATE`이며 `modelInvoked=false`, `externalEgressAttempted=false`다.

## 금지

- 건강상태·사기·의사결정능력 판정
- 서비스·법령·금액·담당기관 창작
- 정책엔진이 허용하지 않은 서비스 추천
- 고객 또는 신뢰연락인에게 자동 전달
- 사건 상태변경 API·금융실행 API 호출
- 외부 LLM·외부 tracing·원격 임베딩 호출

## 사람 검토

행원 화면은 초안임을 표시하고 편집·거절·근거 열람을 제공한다. 승인자는 인용의 적합성, 중립성, 개인정보 최소화, 고객 선택권을 확인한다. 승인 결과는 모델 학습에 자동 사용하지 않는다.
