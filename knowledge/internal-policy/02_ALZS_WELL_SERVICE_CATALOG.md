## 기관 표시 원칙

`안심은행`과 `안심증권`은 시연용 가상 기관이다. 실제 금융회사 공개자료는 서비스 유형의 근거일 뿐, 동일한 조건을 제공한다는 뜻이 아니다. 아래 항목은 전부 `GUIDANCE_ONLY`이며 자동 가입·실행되지 않는다.

## 승인 카탈로그

| 자체 코드 | 기관 | 표시명 | 용도 | 후보 조건 | 실행 |
|---|---|---|---|---|---|
| BANK_CONSULTATION | 공통 | 직원 상담 연결 | 사실확인·쉬운 설명 | 누락·중복·반복확인 또는 고객 요청 | 공식 채널을 안내하고 사람이 처리 |
| SAFE_BLOCK_INFO | 안심은행 | 금융거래 안심차단 안내 | 신규 비대면 거래 등 차단 제도 설명 | 중복송금·피해 우려 또는 고객 요청 | 가능 여부를 금융회사에서 확인 |
| DELAYED_TRANSFER_INFO | 안심은행 | 지연이체 안내 | 이체 후 일정 시간 내 확인 기회 | 고객이 예방 기능 설명을 요청 | 가입·해지는 별도 본인확인 |
| DESIGNATED_NOTICE_INFO | 공통 | 지정인 알림 안내 | 고객이 정한 조건에서 지정인에게 최소 알림 | 별도 동의·범위·기간 존재 | 지정인은 거래권한을 얻지 않음 |
| ACCESSIBILITY_SUPPORT | 공통 | 쉬운 설명·접근성 지원 | 큰 글씨·단계 축소·직원 도움 | 고객 선택 또는 접근성 설정 | 고객이 언제든 변경 |
| TRUSTED_CONTACT_CHECK | 공통 | 신뢰연락인 공동확인 | 본인 확인 후 동의 범위의 최소정보 공유 | 유효한 동의와 수락된 연락인 | 자동 연락 금지, MVP는 전달하지 않음 |
| GUARDIANSHIP_INFO | 공통 | 후견·공공후견 공식정보 | 법적 지원제도와 공식 창구 안내 | 고객·가족의 직접 문의 | 법률판단·서류 자동제출 금지 |
| PUBLIC_SUPPORT_INFO | 공통 | 치매 관련 공공지원 정보 | 센터·비용지원·장기요양·재산관리 안내 | 고객의 직접 필요 선택 | 수급자격 확정 금지 |

현재 코드의 `protection_action_catalog`에 구현된 권위 코드는 `BANK_CONSULTATION`, `SAFE_BLOCK_INFO` 두 개다. 나머지는 문서상 P1 후보이며 구현·승인 전 화면에서 `AVAILABLE`로 표시하지 않는다.

## 공통 필드

모든 서비스 레코드는 `actionCode`, `title`, `actionStatus`, `executionType`, `eligibilitySummary`, `issuer`, `sourceUrl`, `effectiveFrom`, `checkedAt`, `displayOrder`를 가진다. 외부 공공서비스에는 지역·기준연도·공식 확인 연락처를 추가한다.

## 상태

- `AVAILABLE`: 현재 카탈로그에서 안내 가능
- `EXTERNAL_ONLY`: 외부기관 제도이며 존재와 확인 경로만 안내
- `PILOT`: 시범지역·기간을 함께 표시
- `DRAFT`: 내부 승인 전, 검색·화면 노출 금지
- `RETIRED`: 신규 안내 금지, 과거 감사 재현만 허용

## 변경 통제

서비스 추가·조건 변경은 소비자보호와 준법 검토를 모두 거친다. 코드 변경 없이 생성형 AI가 서비스를 새로 만들 수 없다. 실제 회사별 금액·시간·가입조건은 `TBD`로 두며 운영기관 승인 후 별도 버전으로 확정한다.
